# GeminiUnlockerDNS
GeminiUnlockerDNS — это моя программа для обхода ошибки «App unavailable» для нейросетей, таких как Gemini, Claude и ChatGPT. Она работает, подбирая наиболее подходящий DNS-сервер из предустановленного списка. Программа измеряет время отклика каждого сервера (в мс) и сначала проверяет тот, у которого наименьшее значение. Если возникает ошибка, она переходит к следующему, пока не будет найден оптимальный вариант. В настройках программы можно использовать свои DNS-серверы или удалить существующие.
